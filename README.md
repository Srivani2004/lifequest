# ⚔️ LifeQuest - Turn Your Life Into a Game

A gamified productivity application that transforms daily tasks into engaging quests. Complete objectives, earn experience points, unlock achievements, and compete with friends in a fantasy RPG-style interface.

### Core Gameplay
- **Quest System** - Add daily tasks with customizable time estimates (5 min - 3 hours)
- **Time-Based Priority** - Quests automatically sorted by duration; longer tasks reward more XP
- **Dynamic XP Scaling** - Experience rewards scale with task time commitment:
  - 5 minutes = 10 XP
  - 30 minutes = 60 XP
  - 3 hours = 360 XP

### Progression & Rewards
- **Level Up System** - Gain experience to advance character levels
- **Currency** - Earn coins to unlock premium cosmetics
- **Streak Tracking** - Build daily completion streaks
- **Achievement Badges** - 6 unlockable achievements:
  - ✨ First Quest Completed
  - 🔥 7-Day Streak
  - ⭐ Reach Level 5
  - 💫 Earn 100 XP
  - 👑 Acquire 100+ Coins
  - 🏆 Complete 20 Quests

### Customization
- **Avatar Skins** - 4 unlockable character skins (Wizard, Hero, Dragon, King)
- **Free & Premium Options** - Mix of free and paid cosmetics

### Multiplayer
- **PvP Duels** - Challenge friends and track competitive task completion
- **Friend Challenges** - Compete against other players

## 📋 How to Use

1. **Add a Quest**
   - Enter task description in the input field
   - Select estimated completion time
   - Click "Add Quest"

2. **Complete Quests**
   - Click "Complete" button when task is finished
   - Earn XP and coins based on time invested
   - Build your streak

3. **Level Up**
   - Accumulate XP to gain levels
   - Unlock new achievement badges
   - Receive bonus coins at each level

4. **Customize Avatar**
   - Purchase skins with earned coins
   - Display your achievement status

5. **Challenge Friends**
   - Initiate duels with opponents
   - Track task completion vs competitors
   - Win bonus coins for victories
